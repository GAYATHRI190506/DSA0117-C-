\## Tasks



\### Task 01

\*\*Call by Value, Reference and Pointer\*\*



Demonstrates the difference between passing arguments by value, reference and pointer, along with default arguments and returning a reference.



\### Task 02

\*\*Return by Reference and Its Dangers\*\*



Demonstrates returning a reference to an existing variable and explains the danger of returning a reference to a local variable.



\### Task 03

\*\*Default Arguments and Function Overloading\*\*



Demonstrates default function arguments and overloaded functions.



\### Task 04

\*\*Class with Array Inside\*\*



Demonstrates storing an array inside a class and calculating total and average marks using member functions.



\### Task 05

\*\*Static Members and Arrays of Objects\*\*



Demonstrates static data members, static member functions and arrays of class objects.



\### Task 06

\*\*Friend Functions and Inline Functions\*\*



Demonstrates accessing private class data through a friend function and using an inline function.



\### Task 07

\*\*Diagnose, Redesign and Validate\*\*



Demonstrates class design, static members, friend functions, references and account transfer operations.
