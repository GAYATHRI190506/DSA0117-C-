# Task 01 – Understand the Problem and Identify the Objects

## Assignment
DSA01 – C++ Assignment 1

## Assignment Title
Design, Implement and Validate the Fare Logic of a City Metro Smart-Card System

## Task
Task 1 – Understand the Problem and Identify the Objects

## Objective
To analyse the City Metro Smart-Card Fare System from an object-oriented point of view and identify its objects, data, behaviours, system rules, and OOP principles.

## Objects Identified
- SmartCard
- Passenger
- Journey
- Zone
- FareTable

## Concepts Covered
- Object-Oriented Programming
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Procedural vs Object-Oriented Programming
- System rules and constraints

## Alternative Concept
The task also compares the object-oriented approach with a purely procedural approach using global variables and free functions.

## Complexity
The time per journey and memory required per card remain O(1) in both procedural and object-oriented approaches.

## Result
The metro fare system was analysed using an object-oriented approach. The responsibilities of the major objects and the rules that every valid journey must satisfy were identified.
