# Task 04 – Understand Implicit Conversions and Predict Output

## Assignment
DSA01 – C++ Assignment 1

## Task
Task 4 – Understand Implicit Conversions and Predict Output

## Objective
To understand how C++ performs implicit type conversions between different data types and to predict the output of expressions before executing the program.

## Concepts Covered
- Implicit type conversion
- int to double conversion
- double to int conversion
- char to int conversion
- bool to int conversion
- Arithmetic expressions
- Type promotion
- Narrowing conversion
- Output prediction

## Program
The program demonstrates implicit conversions between int, double, char, and bool data types and displays the resulting values.

## Alternative Concept
The same operations can be performed using explicit type casting. Explicit casting gives the programmer control over the target data type.

## Complexity
All conversion and arithmetic operations take O(1) time and O(1) additional space.

## Result
The behaviour of implicit conversions was demonstrated successfully. The program shows how C++ automatically promotes or converts values when different data types are used in an expression.
