### Result

The program successfully implements the City Metro Smart-Card fare logic using switch statements, conditional statements, logical operators and functions.

The program calculates the base fare according to the selected zone, applies the 20% peak-hour surcharge during the specified peak periods, applies student and senior concessions, and validates whether at least Rs 50 remains after the fare.

Boundary cases for the peak-hour periods and minimum balance requirement were also tested.
